
1. FlashList — Performance scrolling
You learn why FlatList freezes on big lists and how FlashList fixes it. This is one of the most asked interview questions for RN devs. Every serious app uses this.

2. Real-time data — WebSocket / Polling
You learn how to make your app update itself without the user doing anything. The match score ticking every second — that's you writing setInterval or connecting a WebSocket. This is how every live sports app, stock app, and chat app works.

3. Deep Linking — Open screens from a URL
You learn how to make your app respond to a link from outside. Someone shares squadscope://player/messi99 in WhatsApp, user taps it, your app opens on that exact screen. This is how Instagram, Twitter, and every big app works with shared links.

4. React Navigation — Stack inside Tabs
You learn the most common real-world navigation pattern. Tabs at the bottom, and inside each tab a full stack of screens. Almost every app on the App Store uses exactly this structure.

5. Skeleton Screens — Loading UX
You learn how to show a fake placeholder that matches the real layout while data is loading. This is what makes apps feel fast and professional instead of showing a spinning wheel.

6. State management under pressure
With live data updating every second across multiple screens, you'll naturally learn how to manage state properly — when to use useState, when to lift state up, and why things re-render.

So in short man — after this one project you know navigation, performance, real-time data, deep linking, and loading UX. Those are the 5 things every RN job posting asks for. That's why this project was designed this way.
